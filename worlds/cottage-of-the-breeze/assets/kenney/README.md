(`LICENSE-house.txt`, `LICENSE-urban.txt`, `LICENSE-factory.txt`).

Downloaded from <https://kenney.nl>; the packed-atlas order was verified byte-equivalent to each
pack's individual `tile_NNNN.png` exports.

These are *optional* — the vefr town renders its map in code (no image sprites required), so these
sheets are a handy art kit for anyone extending the demo world, not a runtime dependency.
